# TP3 : Intents explicites (Développement Mobile, LSI3)

Application Android (Java) qui transfère des données entre deux activités avec un intent explicite.

- `MainActivity` : formulaire (nom, prénom, email) et bouton « Envoyer ».
- `WelcomeActivity` : affiche un message de bienvenue avec les données reçues via `putExtra` / `getExtras`.

Ouvrir le dossier dans Android Studio, attendre la synchronisation Gradle, puis lancer sur un émulateur.
